WIQAYA — VERSION HTML / CSS / JAVASCRIPT

Contenu :
- index.html : structure de la page
- wiqaya.css : styles et responsive design
- wiqaya.js : interactions de la carte, localisation et formulaire d’alerte

Utilisation :
1. Placez les trois fichiers dans le même dossier.
2. Ouvrez index.html dans un navigateur.
3. Pour tester les appels API et la géolocalisation, servez le dossier avec un serveur HTTP local plutôt qu’en file://.

Les incendies affichés sont des données de démonstration. Le formulaire tente d’utiliser l’API Wiqaya et conserve une sauvegarde locale si l’API n’est pas disponible.
